The quantitative measurement of an action, decision, or state. Value is how much something is “worth” to winning a game. An outcome’s value is its measurable quantity: gold, health, mana, cooldown, movement, etc. Value allows for comparing actions or decisions that are measured similarly. Value is discounted over time: a given amount of value now is worth more than the same amount of value later.
