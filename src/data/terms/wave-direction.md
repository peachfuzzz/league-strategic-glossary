term: Wave Direction
tags: [strategy, minions]
active: false

The current direction that a wave is pushing. Wave direction can be described relative to the player, i.e. “away from” and “towards” the player, or it can be described relative to the bases, i.e. “towards red/blue.” A wave’s direction is determined by comparing the rate at which both teams’ minions die: the minions that die more quickly is the direction the entire wave will travel over time. Wave direction is one component of an overall wave state.
