Chose Obsidian as the text editor instead of Google Docs.

## Problem

Google Docs isn't natively Markdown, meaning any markdown functionality had to be scripted elsewhere and imported. All a bit troublesome.

## Rationale

Obsidian already allows for convenient linking and is natively Markdown.

## Pros
- No more import funny business. Editing happens directly in the repository.
- Handles frontmatter nicely

## Cons
- Difficult to share with others
- Less robust editing history
