Giving every concept a unique four digit numerical ID with the prefix `C` (example: C0001).

## Problem

Prior to this, any concept used the term name as its only identifier, so disambiguation and linking became difficult for homonyms.

## Rationale
- 4 digits because it's unlikely there will be more than 10k entries
- C stands for concept
